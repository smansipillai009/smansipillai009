## 🚀 Featured Projects

### 🌀 [Steam Turbine Blade — CAD & FEA]([https://github.com/smansipillai009/Steam-turbine-blade-FEA])

A computational study of a low-pressure-stage steam turbine bucket developed during vocational training at BHEL.

- Built a parametric blade geometry using Python and OpenCASCADE-based tools.
- Developed a workflow for tetrahedral meshing and linear-elastic finite element analysis.
- Explored centrifugal loading, von Mises stress, factor of safety, and displacement.
- Implemented modal analysis and Campbell-diagram-based resonance checks.

**Focus:** Computational solid mechanics · FEA · Modal analysis · Turbomachinery

### 🌉 [Parametric Steel Girder Bridge](https://github.com/smansipillai009/fossee-bridge-model)

A modular 3D CAD model developed for the FOSSEE–IIT Bombay screening task using `pythonOCC`.

- Generated bridge components from configurable geometric parameters.
- Modelled structural components including girders, deck, cross-frames, piers, and reinforcement details.
- Added parameter overrides and STEP/BREP export capabilities.
- Included tests for the bridge model.

**Focus:** Parametric CAD · OpenCASCADE · Python automation · Geometric modelling

### 🦾 [3-DOF Robotic Arm](https://github.com/smansipillai009/Robotic-Arm)

A mechanical engineering project exploring a three-degree-of-freedom robotic arm for obstacle removal.

- Investigates robot mobility and kinematic structure.
- Connects mechanism design with degrees of freedom and Gruebler's criterion.

**Focus:** Mechanisms · Robotics · Kinematics · Mechanical design

### 🛰️ [GaganMitra — Spacecraft Health Monitoring](https://github.com/smansipillai009/GaganMitra)

A practice-model project exploring a spacecraft health-monitoring and decision-support system, developed with Team Mavericks.

The concept focuses on analysing spacecraft telemetry to help identify unusual system behaviour and support engineering decisions.

**Milestone:** Finalist, Supernova 2026.

**Focus:** Space systems · Telemetry · Anomaly detection · Engineering decision support

### 🌌 [Computational Astronomy — Exoplanet Detection](https://github.com/smansipillai009/Astrobit-hackathon-LaLaLand-2026)

A computational astronomy project developed for the IIT Tirupati Computational Astronomy Hackathon.

- Analyses raw Kepler SAP-flux photometry for potential transiting exoplanets.
- Uses a coarse-to-fine Box Least Squares (BLS) search followed by machine-learning-based candidate vetting.

**Milestone:** First place, IIT Tirupati Computational Astronomy Hackathon.

**Focus:** Scientific Python · Time-series analysis · Machine learning · Astronomy
